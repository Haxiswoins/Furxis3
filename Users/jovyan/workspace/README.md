# Next.js Project for Firebase Studio

This is a Next.js starter project configured for use within Firebase Studio.

To get started, explore the main application pages located in the `src/app/(main)` directory, with the homepage being `src/app/(main)/home/page.tsx`.

To synchronize your local code changes with your personal GitHub repository, you can run the `SYNC_TO_GIT.sh` script in the terminal.
