
# Resend 邮件发送功能部署指南

本文档将详细指导您如何设置 [Resend](https://resend.com/) 邮件服务，从而让您的网站具备自动发送邮件通知（如新订单提醒、中标通知）的能力。

---

### **为什么需要 Resend？**

您的网站在以下几种情况会自动发送邮件：
1.  当有用户提交新的**委托**或**领养**申请时，系统会自动向您的管理员邮箱发送一封提醒邮件。
2.  当您在后台将某个委托订单的状态修改为 **“待确认”** 或 **“未中标”** 时，系统会自动向该用户发送一封通知邮件。
3.  当有用户提交**退养/取消**申请时，系统会通知管理员。

没有正确配置 Resend，以上功能将无法工作。

---

### **第 1 步：注册 Resend 账户**

1.  请访问 [resend.com](https://resend.com/)。
2.  点击 "Sign up" 或 "Get Started" 按钮，使用您的邮箱完成注册流程。

---

### **第 2 步：获取您的 API 密钥**

API 密钥是您的网站用来和 Resend 服务进行安全通信的“钥匙”。

1.  登录到您的 Resend 账户。
2.  在左侧导航栏中，找到并点击 **"API Keys"**。
3.  点击 **"+ Create API Key"** 按钮。
4.  为您的密钥取一个名字，例如 `Forward Infinity Project`。
5.  在 **Permission** 处，请选择 **"Sending access"**。这是更安全的“最小权限原则”，它只允许此密钥用于发送邮件。
6.  点击 **"Add"** 按钮。
7.  **非常重要**：Resend 现在会显示您的 API 密钥，它看起来像 `re_...`。**请立即复制这个密钥并妥善保管**，因为出于安全考虑，这个完整的密钥只会出现这一次。

---

### **第 3 步：添加并验证您的发信域名 (最关键的一步)**

为了能以您自己的名义（例如 `notification@yourdomain.com`）发送邮件，而不是通过 Resend 的默认地址，您必须添加并验证您拥有这个域名。

1.  在 Resend 的左侧导航栏中，点击 **"Domains"**。
2.  点击 **"+ Add Domain"** 按钮。
3.  输入您拥有的域名（例如 `yourdomain.com`），然后点击 "Add"。
4.  Resend 会为您生成 **DNS记录**。这些是需要您添加到您的域名解析服务商（如 GoDaddy, Cloudflare, 阿里云/腾讯云）的记录。
5.  请登录到您的域名提供商的管理后台，找到DNS解析设置，然后**逐字逐句**地将 Resend 提供的这几条记录添加进去。
6.  添加完毕后，回到 Resend 的域名页面。验证过程可能需要几分钟到几小时不等。您可以点击域名旁边的 **"Verify"** 按钮来刷新状态。当所有记录都显示为绿色的 **"Verified"** 状态时，就代表成功了！

> **⚠️ 提示**: 如果您没有自己的域名，Resend 允许您在测试阶段每天从 `onboarding@resend.dev` 这个地址发送少量邮件，但这**不是**生产环境的解决方案。要正式运营，验证自己的域名是必需的。

---

### **第 4 步：在您的网站后台配置邮箱**

现在，我们将刚才获取的API密钥和验证过的域名配置到您的网站项目中。

1.  **配置API Key**: 在您的项目根目录中，找到或创建 `.env.local` 文件。打开这个文件，找到名为 `RESEND_API_KEY` 的变量。将您在第2步中复制的 `re_...` 密钥粘贴到等号后面。

    ```
    RESEND_API_KEY="re_xxxxxxxxxxxxxxxxx"
    ```

2.  **配置发件人地址**: 这是**必须操作**的一步。
    *   登录您的网站后台管理页面。
    *   进入 **页面内容管理** -> **全局设置**。
    *   找到 **“系统发件邮箱 (发件)”** 输入框。
    *   在这里填入一个您想用来发送系统邮件的地址，例如 `noreply@your-domain.com`。
    *   **极其重要**: 您在此处填写的邮箱地址，其**域名部分** (`your-domain.com`) **必须是**您在第3步中于Resend成功验证过的域名，否则所有邮件都将发送失败。

---

### **第 5 步：重启您的应用**

如果您之前已经启动了应用 (`npm run dev` 或 `npm start`)，请务必**重启它**，这样新的环境变量才能被正确加载。

至此，您的邮件发送功能已经全部配置完毕！现在您可以去网站上提交一个测试订单，然后检查您的管理员邮箱是否收到了通知邮件，以验证一切是否正常工作。
