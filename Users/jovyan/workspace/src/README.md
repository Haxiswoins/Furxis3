
# 前行无界 (Forward Infinity) - Firebase Studio 项目

这是一个为“前行无界”工作室定制的网站项目，使用 Next.js 构建，并已在 Firebase Studio 中完成初始化。

## 快速上手

*   **首页**: `src/app/(main)/home/page.tsx`
*   **入口页 (Landing Page)**: `src/app/page.tsx`

## 版本控制与同步

为了将您在 Firebase Studio 中所做的更改备份并同步到您自己的 GitHub 仓库，请使用项目根目录下的 `sh SYNC_TO_GIT.sh` 脚本。

详细的 Git 工作流程请参考 `GIT_GUIDE.md`。

## 部署

关于如何将此项目部署到您自己的服务器，请详细阅读 `DEPLOY_GUIDE.md` 文件。
